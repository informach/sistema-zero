# BUG-003: Modo livre de addon gera import inválido

**Severity:** Low
**Priority:** P3
**Type:** Functional
**Status:** Fixed

## Environment

- **Build:** 70ca10c6 + worktree atual
- **OS:** Microsoft Windows NT 10.0.26200.0
- **Browser:** Chromium via Playwright 1.60.0; reprodução principal em Bun
- **URL:** Studio / Canvas 3D / bloco “usar … da biblioteca”

## Summary

O campo livre do importador de addons aceita vários nomes ou um nome customizado, mas o resolvedor automático possui somente um módulo. Isso pode gerar um import que pede exports ao módulo errado ou usa literalmente `automático` como especificador.

## Reproduction

```ts
block.setFieldValue('GLTFLoader, OrbitControls', 'NAMES')
block.setFieldValue('automático', 'MODULE')
const statement = buildIRFromWorkspace(workspace).behavior.start[0]
console.log(generateJS({ statements: [statement] }))
```

Observed before the fix:

```js
import { GLTFLoader, OrbitControls } from 'three/addons/loaders/GLTFLoader.js';
```

O módulo exporta `GLTFLoader`, não `OrbitControls`. Para um nome desconhecido e módulo automático, o gerador emite `from 'automático'`.

## Expected

O modo automático deve sempre produzir imports resolvíveis. Entradas de módulos diferentes devem virar imports separados ou ser rejeitadas com orientação clara; `automático` nunca deve chegar ao JavaScript.

## Root cause

`buildIR.ts` separa `NAMES` por vírgula e escolhe o primeiro módulo conhecido com `.find(Boolean)`, preservando todos os nomes. Se nenhum nome for conhecido, mantém o próprio valor `automático`.

## Fix

Aplicado em `canvas3dAddons.ts`, `buildIR.ts` e `schema.ts`. O catálogo agora resolve e agrupa cada nome pelo módulo canônico, emitindo um statement por módulo. Se algum nome livre não tiver resolução, o marcador `automático` permanece somente na IR intermediária e o schema exige um caminho explícito antes da geração.

## Verification

- PASS — um item curado continua gerando seu módulo canônico.
- PASS — `GLTFLoader, OrbitControls` vira dois imports canônicos.
- PASS — nome customizado no modo automático falha com orientação para informar o caminho e passa após o módulo explícito.

## Impact

- **Users Affected:** usuários do modo livre/avançado do picker de addons
- **Frequency:** sempre para vários addons de módulos diferentes; sempre para custom sem módulo explícito
- **Workaround:** não necessário após a correção

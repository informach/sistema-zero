# BUG-001: Ponte classifica métodos homônimos pelo projeto inteiro

**Severity:** Medium
**Priority:** P2
**Type:** Functional
**Status:** Fixed

## Environment

- **Build:** 70ca10c6 + worktree atual
- **OS:** Microsoft Windows NT 10.0.26200.0
- **Browser:** não aplicável; reprodução determinística em Bun
- **URL:** Studio / Ponte / categoria Canvas 3D

## Summary

Quando qualquer statement de topo ativa Three.js, a volta IR → Blockly converte métodos e propriedades homônimos de objetos JavaScript comuns em blocos Canvas 3D. Quando o sinal 3D existe somente dentro de um evento, ocorre o inverso e facilitadores válidos deixam de ser reconhecidos.

## Reproduction

```ts
const source = [
  "import * as THREE from 'three';",
  'const cena = new THREE.Scene();',
  'const itens = new Set();',
  "itens.add('moeda');",
  'const estado = { visible: false };',
  'estado.visible = true;',
].join('\n')
const json = JSON.stringify(buildWorkspaceStateFromIR({
  html: [], css: [], extensions: [], js: parseJS(source),
}))
```

Observed before the fix:

- `sz_t3d_add_to: true`; `sz_js_method_on: false`.
- `sz_t3d_set_visible: true`; `sz_js_member_set: false`.
- Com todos os sinais Canvas 3D somente no corpo de um evento, `threeSceneSetup` e `new THREE.Group()` são amigáveis, mas `cena.add(grupo)` vira `sz_js_method_on`.

## Expected

Somente bindings com capacidade Canvas 3D compatível devem virar facilitadores 3D, independentemente de outros objetos comuns existirem no mesmo projeto ou do statement estar aninhado.

## Root cause

`buildWorkspaceStateFromIR` define um booleano global com `allStatements.some(statementUsesCanvas3D)`. `recognizeT3dCall` e `recognizeT3dSet` verificam esse booleano, não a origem/capacidade do receptor. `statementUsesCanvas3D` também não percorre corpos recursivamente.

## Fix

Aplicado em `programmingReferences.ts` e `workspaceState.ts`. A Ponte agora consome um índice recursivo por statement, sensível à ordem, callbacks, escopo e shadowing. Cada recognizer exige a capacidade do receptor (cena, objeto, renderizador, câmera, compositor, luz etc.); o latch global e os coletores globais de imports/loaders foram removidos.

## Verification

- PASS — projeto misto mantém `Set.add` em `sz_js_method_on` e objeto comum `.visible` em `sz_js_member_set`.
- PASS — recursos Canvas 3D aninhados continuam voltando como facilitadores.
- PASS — shadowing léxico por variável local impede classificação 3D indevida.

## Impact

- **Users Affected:** alunos que misturam Three.js e objetos JavaScript comuns ou criam a cena dentro de callbacks
- **Frequency:** sempre para as assinaturas homônimas reproduzidas
- **Workaround:** não necessário após a correção

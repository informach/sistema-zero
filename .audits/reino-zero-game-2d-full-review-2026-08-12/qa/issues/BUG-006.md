# BUG-006: Tooltip do bloco de tela viola o contrato textual

**Severity:** Low
**Priority:** P3
**Type:** UI
**Status:** Fixed (verificado novamente em 2026-08-13)

## Environment

- **Build:** worktree local de 2026-08-12
- **OS:** Windows
- **Browser:** N/A
- **URL:** paleta do Jogo 2D

## Summary

O tooltip de `sz_g2d_show_image_screen` usa travessão e reticências tipográficas, apesar do contrato central exigir linguagem visível simples e sem travessões.

## Reproduction

```bash
bun test src/blockly/__tests__/blockContracts.test.ts
```

Observed before the fix:

- 25 testes aprovados e 1 falha.
- Offender: `sz_g2d_show_image_screen`.

## Expected

O texto visível deve seguir a convenção central e o teste deve passar.

## Root cause

O tooltip novo foi adicionado com os caracteres proibidos sem executar o contrato global antes do fechamento.

## Fix

O travessão foi substituído por dois-pontos numa edição concorrente do worktree.

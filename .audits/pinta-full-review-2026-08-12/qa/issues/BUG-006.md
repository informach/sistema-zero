# BUG-006: Modal fecha após falha de inserção

**Severity:** Low
**Priority:** P3
**Type:** UI
**Status:** Fixed

## Environment

- **Build:** c9984b60 + working tree de 2026-08-12
- **OS:** Windows
- **Browser:** Independente de browser no fluxo de controle
- **URL:** Pinta → Vetor → Trazer um desenho

## Summary

O modal fecha incondicionalmente depois de chamar a inserção, inclusive quando a inserção termina antes do commit por canvas ausente, PNG grande, asset vazio ou teto de shapes.

## Reproduction

```text
1. Abrir o seletor em documento próximo de PINTA_LIMITS.maxShapes.
2. Escolher um asset cuja quantidade ultrapasse o teto.
3. Observar o toast e o fechamento do modal.
```

Observed before the fix:

- `insertFromAsset` retorna sem commit e mostra toast; `onClose()` é chamado na linha seguinte sem ler resultado.

## Expected

Falha mantém o modal aberto, preserva busca/seleção e mostra a causa; sucesso fecha.

## Root cause

O comando retorna `void`, então a UI não diferencia commit de recusa.

## Fix

`insertFromAsset` retorna booleano e o seletor chama `onClose()` somente quando recebe sucesso.

## Verification

- `vectorUi.test.tsx` força a falha de rasterização do desenho pixel no happy-dom e confirma que o modal permanece aberto.

## Impact

- **Users Affected:** quem encontra uma recusa de inserção.
- **Frequency:** sempre nos ramos de falha.
- **Workaround:** reabrir o seletor e ajustar o documento.

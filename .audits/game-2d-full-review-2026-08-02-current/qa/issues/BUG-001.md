# BUG-001: bloco legado removido descarta o workspace

**Severity:** Critical
**Priority:** P0
**Type:** Data
**Status:** Open

## Environment

- **Build:** game-2d 0.57.0, worktree corrente sobre `8c97ae05`
- **OS:** Windows NT 10.0.26200.0
- **Browser:** N/A
- **URL:** importação/reidratação de projeto no Studio

## Summary

Um projeto salvo com `sz_g2d_update_group_no_gravity` é tratado como contendo
bloco desconhecido e perde todo o `blocksState`. O IR e a chamada JavaScript
correspondentes também deixaram de ser aceitos.

## Reproduction

```bash
bun -e "import { sanitizeImportedBlocksState, collectUnknownBlockTypes } from './src/state/projectStore.ts'; const installed=[{id:'game-2d',version:'0.56.0'}]; const state={blocks:{languageVersion:0,blocks:[{type:'sz_g2d_update_group_no_gravity',id:'legacy'}]}}; console.log(JSON.stringify({unknown:collectUnknownBlockTypes(state,installed),sanitized:sanitizeImportedBlocksState(state,installed)}));"
```

Observed before the fix:

- `unknown` contém `sz_g2d_update_group_no_gravity`.
- `sanitized` é `null`.
- `JSStatementSchema.safeParse({type:'g2d:updateGroupNoGravity', ...})` falha.
- `typeof SZGame2D.updateGroupNoGravity` é `undefined`.

## Expected

Projetos publicados desde a v0.25 devem reabrir sem perda de blocos e preservar
o comportamento do helper antigo.

## Root cause

O bloco, statement, parser, gerador e método antigos foram substituídos pela
nova operação de gravidade. A allowlist é derivada só do catálogo corrente e a
sanitização ocorre antes de qualquer migração compatível.

## Fix

Não aplicado. Restaurar o bloco oculto e o alias de runtime; aceitar o statement
antigo na entrada; migrar antes da allowlist e adicionar fixtures históricas.

## Verification

- A reprodução acima ainda retorna `sanitized:null`.
- A suíte atual não possui fixture desse bloco publicado.

## Impact

- **Users Affected:** projetos game-2d v0.25.0-v0.56.0 que usam o bloco
- **Frequency:** always ao reabrir/importar esse workspace
- **Workaround:** none seguro para crianças; só edição manual do JSON/código

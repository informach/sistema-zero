# BUG-005: 179 blocos 2D são liberados de uma vez no tier 3D

**Severity:** Medium
**Priority:** P2
**Type:** UI
**Status:** Open

## Environment

- **Build:** game-2d 0.57.0, worktree corrente sobre `8c97ae05`
- **OS:** Windows NT 10.0.26200.0
- **Browser:** Chromium / toolbox Blockly
- **URL:** Studio com `level=iniciante-3d`

## Summary

O primeiro degrau mostra 37 blocos do Jogo 2D; o degrau seguinte libera os 179
restantes de uma só vez e também todos os blocos do Jogo 3D. O nome do degrau e
a carga cognitiva não representam o conteúdo liberado.

## Reproduction

```bash
bun -e "import { gameTwoDBlocks } from './src/official-extensions/game-2d/blocks.ts'; import { resolveBlockLevel } from './src/blockly/blockLevels.ts'; console.log(Object.groupBy(gameTwoDBlocks,b=>resolveBlockLevel(b.type)))"
```

Observed before the fix:

- `iniciante-2d`: 37 blocos game-2d.
- `iniciante-3d`: 179 blocos game-2d, além do catálogo 3D.
- Catálogo total: 216 blocos em 24 subcategorias.

## Expected

O avanço deve liberar conjuntos 2D progressivos e localizáveis, ou comunicar
claramente que o degrau abre o catálogo 2D completo junto com o 3D.

## Root cause

Todo `sz_g2d_*` fora do perfil essencial cai por default em
`iniciante-3d`; não há tiers intermediários por domínio 2D.

## Fix

Não aplicado. Usar perfis/allowlists progressivos por curso e validar a
descoberta de blocos com crianças; revisar o rótulo do degrau se a regra ficar.

## Verification

- Contagem derivada do catálogo e do resolver reais.
- Testes atuais aprovam essa regra, mas não medem usabilidade.

## Impact

- **Users Affected:** alunos que avançam de iniciante-2d para iniciante-3d
- **Frequency:** always ao abrir a toolbox nesse tier
- **Workaround:** aulas podem fornecer `allowBlocks` restritivo

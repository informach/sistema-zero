# BUG-003: snapshot dos exemplos quebrou a suíte global

**Severity:** High
**Priority:** P1
**Type:** Functional
**Status:** Fixed during review

## Environment

- **Build:** game-2d 0.57.0, worktree corrente sobre `8c97ae05`
- **OS:** Windows NT 10.0.26200.0
- **Browser:** N/A
- **URL:** CI/testes do package Studio

## Summary

O conteúdo dos 31 exemplos mudou, mas o SHA-256 esperado no teste de catálogo
lazy não foi atualizado na primeira execução. A suíte global do Studio falhou;
outra alteração no worktree corrigiu o golden enquanto o review estava ativo.

## Reproduction

```bash
bun test src/official-extensions/examplesLoading.test.ts
```

Observed before the fix:

- Expected: `65bff9fac46115405500f406f0209e6a213e5d6d30b29ba17716dc854634b41d`
- Received: `c7f5657ed78274e40a7d2269a47dd3678c5652a1513dde1cd243eaf2ae6856bc`
- Suíte global: 6.461 pass, 1 fail.

## Expected

O golden deve representar exatamente o catálogo validado que será publicado, e
o gate global deve passar.

## Root cause

As fontes/IRs de exemplos foram alteradas sem atualizar o snapshot central em
`examplesLoading.test.ts`.

## Fix

O golden foi atualizado em paralelo por outra alteração do usuário. Este review
não modificou o teste nem o catálogo.

## Verification

- Falha reproduzida isoladamente antes da atualização.
- Verificação final isolada: 2 pass, 0 fail.
- Verificação final global: 6.462 pass, 0 fail, 70.626 expects.
- Os 31 exemplos também passaram no Chromium.

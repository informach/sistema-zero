# BUG-002: Script dinâmico contorna guard de loops

**Severity:** Critical  
**Priority:** P0  
**Type:** Crash  
**Status:** Open

## Environment

- **Build:** `9c5bb92c`
- **OS:** Windows
- **Browser:** Chromium
- **URL:** preview do Studio

## Summary

Blocos guiados de DOM conseguem anexar um `<script>` inline com loop infinito, fora do código instrumentado pelo guard.

## Reproduction

```js
const pagina = document.querySelector('body')
const codigo = document.createElement('script')
codigo.textContent = 'while (true) {}'
pagina.appendChild(codigo)
```

Observed before the fix:

- `instrumentLoops` não altera o loop contido na string.
- A CSP permite script inline, que executa no mesmo thread da aba.

## Expected

Código criado pelo projeto não deve conseguir executar loops fora da proteção do preview.

## Root cause

A criação de tags aceita `script`, enquanto a CSP usa `'unsafe-inline'` e a instrumentação ocorre apenas no JavaScript canônico.

## Fix

Pendente: negar tags executáveis em todos os caminhos e endurecer a CSP com nonce/hash.

## Verification

- Teste de validação para `script` e equivalentes SVG.
- E2E que confirme recusa e responsividade contínua da IDE.

## Impact

- **Users Affected:** todos os usuários do modo guiado
- **Frequency:** sob composição específica de blocos
- **Workaround:** evitar criar tags executáveis

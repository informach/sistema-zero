# BUG-007: Laços reavaliam limites e falham ao decrescer

**Severity:** Medium  
**Priority:** P2  
**Type:** Functional  
**Status:** Open

## Environment

- **Build:** `9c5bb92c`
- **OS:** Windows
- **Browser:** N/A
- **URL:** blocos de repetição

## Summary

O repeat recalcula expressões de limite a cada iteração e o for-range usa sempre `<`, inclusive com passo negativo.

## Reproduction

```js
for (let i = 0; i < Math.random() * 10; i++) {}
for (let i = 3; i < 0; i += -1) {}
```

Observed before the fix:

- O limite aleatório muda durante o laço.
- O intervalo decrescente não executa.

## Expected

Limites devem ser avaliados uma vez e intervalos decrescentes devem usar a comparação correta.

## Root cause

O gerador interpola expressões diretamente e fixa o operador `<`.

## Fix

Pendente: temporários únicos, comparação por sinal e tratamento de passo zero.

## Verification

- Cobrir efeitos colaterais, subida, descida e passo zero.

## Impact

- **Users Affected:** alunos usando limites dinâmicos ou intervalos decrescentes
- **Frequency:** sempre nesses casos
- **Workaround:** usar limites literais e laço manual

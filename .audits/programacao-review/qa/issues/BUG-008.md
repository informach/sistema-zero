# BUG-008: Shuffle é enviesado e altera a lista

**Severity:** Medium  
**Priority:** P2  
**Type:** Functional  
**Status:** Open

## Environment

- **Build:** `9c5bb92c`
- **OS:** Windows
- **Browser:** N/A
- **URL:** bloco de embaralhar lista

## Summary

O bloco usa `sort(() => Math.random() - 0.5)`, que não produz permutação uniforme e modifica a lista original implicitamente.

## Reproduction

```text
Gerar JavaScript para uma expressão IR arrayShuffle.
```

Observed before the fix:

- Saída: `lista.sort(() => Math.random() - 0.5)`.

## Expected

Distribuição uniforme e contrato explícito sobre cópia versus mutação.

## Root cause

Implementação simplificada por comparador aleatório, duplicada em relação ao Fisher–Yates já existente no pacote.

## Fix

Pendente: helper Fisher–Yates canônico com semântica documentada.

## Verification

- Invariantes de permutação e teste estatístico tolerante.
- Round-trip do parser.

## Impact

- **Users Affected:** jogos de cartas/memória e listas aleatórias
- **Frequency:** sempre, com viés variável
- **Workaround:** implementar Fisher–Yates manualmente

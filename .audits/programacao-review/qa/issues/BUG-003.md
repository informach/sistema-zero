# BUG-003: Eventos e `this` têm contratos divergentes

**Severity:** High  
**Priority:** P1  
**Type:** Functional  
**Status:** Open

## Environment

- **Build:** `9c5bb92c`
- **OS:** Windows
- **Browser:** N/A
- **URL:** editor de blocos

## Summary

IR, checker Blockly e textos pedagógicos aceitam modelos diferentes para eventos dentro de funções e para `this`.

## Reproduction

```text
Criar função que usa sz_val_this e conectá-la como handler de sz_js_on_event_named.
```

Observed before the fix:

- A conexão de `sz_val_this` dentro da função é rejeitada.
- O schema aceita registros de evento em corpo de função que o editor não permite montar.

## Expected

Importação, montagem interativa, persistência e copy devem compartilhar o mesmo contrato contextual.

## Root cause

Regras independentes em `ir/lifecycle.ts`, `blockContracts.ts` e `htmlConnectionChecker.ts` derivaram.

## Fix

Pendente: centralizar o modelo; separar `this` de classe e elemento atual de evento se necessário.

## Verification

- Round-trip código → blocos → reconexão interativa.
- Matriz de contextos de evento, função e classe.

## Impact

- **Users Affected:** alunos usando handlers nomeados/funções/classes
- **Frequency:** sempre nas composições divergentes
- **Workaround:** escrever o handler de outra forma

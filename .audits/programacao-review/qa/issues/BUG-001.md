# BUG-001: Restauração com parâmetros perde blocos

**Severity:** Critical  
**Priority:** P0  
**Type:** Data  
**Status:** Open

## Environment

- **Build:** `9c5bb92c`
- **OS:** Windows
- **Browser:** Playwright Chromium
- **URL:** `http://127.0.0.1:5195`

## Summary

Projetos com `sz_val_arg` podem reabrir com apenas uma fração dos blocos, embora o preview continue funcionando e o E2E atual passe.

## Reproduction

```bash
cd packages/studio
bunx playwright test e2e/core-example-invaders.spec.ts
```

Observed before the fix:

- stderr: `The block "sz_val_arg" ... could not connect`.
- Reprodução isolada do mesmo `blocksState`: 15 blocos carregados para cerca de 481 nós serializados.

## Expected

O workspace deve restaurar toda a estrutura sem warnings ou perda de blocos.

## Root cause

O checker contextual valida `sz_val_arg` antes de o mutator/escopo do parâmetro estar completamente restaurado.

## Fix

Pendente: tornar a validação segura durante desserialização ou adiá-la até o contexto estar completo.

## Verification

- Exigir ausência de warning de `blocksState`.
- Conferir contagem e blocos contextuais representativos no E2E.

## Impact

- **Users Affected:** alunos com projetos de funções/classes
- **Frequency:** sempre que a estrutura serializada atinge o caminho incompatível
- **Workaround:** nenhum confiável no editor visual

# BUG-005: `allowBlocks` produz categorias fantasma ou duplicadas

**Severity:** High  
**Priority:** P1  
**Type:** UI  
**Status:** Open

## Environment

- **Build:** `9c5bb92c`
- **OS:** Windows
- **Browser:** N/A
- **URL:** toolbox Programação

## Summary

A curadoria por aula pode mostrar categoria vazia ou duplicar blocos compartilhados, apesar de `allowBlocks` declarar um conjunto exato.

## Reproduction

```text
Perfil A: allowBlocks = ['sz_js_call_method'].
Perfil B: allowBlocks = ['sz_js_function', 'sz_js_return', 'sz_val_arg'].
```

Observed before the fix:

- Perfil A cria Classes, mas o flyout é vazio.
- Perfil B cria Funções e Classes, com retorno duplicado.

## Expected

Cada tipo permitido deve ser alcançável e nenhuma categoria/bloco extra deve aparecer.

## Root cause

Catálogo estático, filtro local de legados e flyouts contextuais mantêm metadados concorrentes.

## Fix

Pendente: uma fonte única de ofertabilidade/grupo/contexto e criação de categoria baseada no flyout efetivo.

## Verification

- Para cada tipo ofertável, testar `allowBlocks: [tipo]`.
- Asserir flyout não vazio e conjunto exato.

## Impact

- **Users Affected:** aulas com paleta restrita
- **Frequency:** nos blocos legados/compartilhados afetados
- **Workaround:** configurar listas específicas evitando esses tipos

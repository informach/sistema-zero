# BUG-004: Fetch JSON aceita erro HTTP como sucesso

**Severity:** High  
**Priority:** P1  
**Type:** Functional  
**Status:** Open

## Environment

- **Build:** `9c5bb92c`
- **OS:** Windows
- **Browser:** N/A
- **URL:** bloco `fetch JSON`

## Summary

Respostas HTTP 4xx/5xx executam o callback de sucesso quando possuem corpo JSON válido.

## Reproduction

```text
Executar o código gerado com fetch retornando { ok: false, status: 404, json: async () => ({}) }.
```

Observed before the fix:

- O callback de sucesso é chamado; o caminho `catch` não é usado.

## Expected

HTTP não bem-sucedido deve acionar o caminho de erro prometido pelo bloco.

## Root cause

O gerador chama `resposta.json()` sem verificar `resposta.ok`.

## Fix

Pendente: lançar erro com status antes do parse do JSON.

## Verification

- Testar 404, 500, JSON inválido, falha de rede e sucesso.
- Atualizar round-trip do parser para a forma canônica.

## Impact

- **Users Affected:** alunos consumindo APIs
- **Frequency:** todo erro HTTP com JSON legível
- **Workaround:** checar status manualmente fora do bloco

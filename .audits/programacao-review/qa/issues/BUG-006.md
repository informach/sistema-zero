# BUG-006: `filter` omite variável local no picker

**Severity:** Medium  
**Priority:** P2  
**Type:** UI  
**Status:** Open

## Environment

- **Build:** `9c5bb92c`
- **OS:** Windows
- **Browser:** N/A
- **URL:** bloco `filtrar lista`

## Summary

O item local declarado pelo bloco `sz_val_array_filter` não aparece no seletor de variáveis aninhado.

## Reproduction

```text
Criar filter com ITEM=inimigo, aninhar sz_val_variable e abrir o picker.
```

Observed before the fix:

- `collectScopedVariableNames` retorna lista vazia.

## Expected

O picker deve oferecer `inimigo`, como já ocorre em map/find.

## Root cause

`VARIABLE_LOOP_BINDERS` omite `sz_val_array_filter`.

## Fix

Pendente: adicionar o binder e teste de paridade.

- Testar map, find e filter com variáveis locais.

- **Users Affected:** alunos usando filter
- **Frequency:** sempre

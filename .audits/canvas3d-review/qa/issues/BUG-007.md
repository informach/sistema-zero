# BUG-007: `|` em ID físico corrompe contatos ativos

**Severity:** Low
**Priority:** P3
**Type:** Functional
**Status:** Fixed

## Environment

- **Build:** 70ca10c6 + worktree atual
- **OS:** Windows NT 10.0.26200.0
- **Browser:** runtime isolado
- **URL:** Física leve de Canvas 3D

## Summary

IDs aceitam o mesmo caractere usado como delimitador interno, tornando ambígua a limpeza de colisões/triggers.

## Reproduction

```text
Crie contato com colisor `parede|um`, remova-o, recrie-o e provoque novo contato.
```

Observed before the fix:

- O segundo evento fica suprimido; com ID `parede`, os dois eventos são emitidos.

## Expected

Qualquer ID aceito deve ser tratado sem colisão com a codificação interna.

## Root cause

As chaves concatenam IDs por `|` e `clearActiveFor` tenta desmontá-las com `split('|')`.

## Fix

As chaves internas de contato agora usam componentes com comprimento prefixado e podem ser consultadas sem `split('|')` ambíguo.

## Verification

- A regressão remove e recria IDs com `|` e confirma dois eventos tanto para colisões quanto para triggers.

## Impact

- **Users Affected:** projetos com `|` em nomes físicos
- **Frequency:** sempre após remover/recriar nesse caso
- **Workaround:** usar IDs alfanuméricos simples

# BUG-005: Sentinela em texto quebra o macro semântico

**Severity:** Medium
**Priority:** P2
**Type:** Data
**Status:** Fixed

## Environment

- **Build:** 70ca10c6 + worktree atual
- **OS:** Windows NT 10.0.26200.0
- **Browser:** N/A
- **URL:** Ponte Código ↔ Blocos

## Summary

Um valor de texto válido contendo a sentinela interna de fim faz o scanner encerrar o macro antes da hora e perder o bloco facilitador.

## Reproduction

```text
Crie um `signSetup` com texto `/*__SZ_CANVAS3D_END__*/`.
Gere JavaScript e faça parseJS do resultado.
```

Observed before the fix:

- O resultado não contém `signSetup`; a receita reaparece fragmentada em statements de baixo nível.

## Expected

Conteúdo do aluno não deve ser interpretado como framing interno.

## Root cause

O scanner usa `indexOf` em texto cru e não restringe marcadores a linhas de metadado.

## Fix

O macro v2 carrega o comprimento exato do corpo no cabeçalho. O scanner não procura a sentinela de fim dentro do conteúdo do aluno e o fallback reconhece somente marcadores em posição válida de linha.

## Verification

- A regressão confirma que um letreiro contendo a sentinela preserva `signSetup` no round-trip.

## Impact

- **Users Affected:** projetos cujo texto/código contém a sentinela
- **Frequency:** rara, mas determinística
- **Workaround:** não usar o token reservado no texto

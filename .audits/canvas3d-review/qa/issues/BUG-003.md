# BUG-003: Qualquer namespace vira bloco Canvas 3D

**Severity:** Medium
**Priority:** P2
**Type:** Functional
**Status:** Fixed

## Environment

- **Build:** 70ca10c6 + worktree atual
- **OS:** Windows NT 10.0.26200.0
- **Browser:** N/A
- **URL:** Ponte Código → Blocos

## Summary

Construtores de bibliotecas não relacionadas, como PIXI ou uma API própria, são reconstruídos como blocos Canvas 3D.

## Reproduction

```js
const app = new PIXI.Application();
const cliente = new API.Client();
```

Observed before the fix:

- Ambos reabrem como `sz_t3d_new_var`, não como `sz_js_new_var`.

## Expected

Somente `THREE.X` e addons importados de Three devem virar Canvas 3D.

## Root cause

`workspaceState` usa a mera presença de `namespace` como sinal de Three.js.

## Fix

A Ponte reconhece Canvas 3D somente para `THREE.X` ou classe bare efetivamente importada de Three/addons. Construtores externos preservam namespace e usam blocos genéricos.

## Verification

- As regressões confirmam que `PIXI.Application` e `API.Client` permanecem genéricos e fazem round-trip byte a byte.

## Impact

- **Users Affected:** projetos que misturam bibliotecas/classes namespaced
- **Frequency:** sempre para `new X.Y()`
- **Workaround:** evitar alternar para Blocos nesse código

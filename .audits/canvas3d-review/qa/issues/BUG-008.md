# BUG-008: LineMaterial não aparece como alvo de cor

**Severity:** Low
**Priority:** P3
**Type:** Functional
**Status:** Fixed

## Environment

- **Build:** 70ca10c6 + worktree atual
- **OS:** Windows NT 10.0.26200.0
- **Browser:** N/A
- **URL:** Canvas 3D / seletor “cor de”

## Summary

O Studio oferece `LineMaterial` como addon suportado, mas não reconhece a variável como material colorível.

## Reproduction

```text
Importe LineMaterial, crie `linhaMat = new LineMaterial(...)` e abra o seletor do bloco “cor de”.
```

Observed before the fix:

- `linhaMat` não é oferecido e a validação rejeita a referência.

## Expected

`LineMaterial` deve ser `color-target3d`, pois sua API expõe `color: Color`.

## Root cause

A allowlist `COLOR_TARGET_MATERIAL_CLASS_NAMES` omite a classe curada.

## Fix

`LineMaterial` foi incluído na allowlist de materiais coloríveis do contrato Canvas 3D.

## Verification

- A regressão confirma que `canvas3DSymbolKindsForClass('LineMaterial')` inclui `color-target3d`.

## Impact

- **Users Affected:** usuários de linhas largas avançadas
- **Frequency:** sempre
- **Workaround:** definir a cor no construtor ou usar código avançado

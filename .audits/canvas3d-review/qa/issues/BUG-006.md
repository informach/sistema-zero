# BUG-006: Checksum ignora o payload semântico

**Severity:** Low
**Priority:** P3
**Type:** Data
**Status:** Fixed

## Environment

- **Build:** 70ca10c6 + worktree atual
- **OS:** Windows NT 10.0.26200.0
- **Browser:** N/A
- **URL:** Codec de macros Canvas 3D

## Summary

É possível trocar um payload semântico válido sem alterar o JavaScript visível nem invalidar o checksum.

## Reproduction

```text
Gere macro de partículas com count=1; troque só o payload percent-encoded para count=999; faça parse.
```

Observed before the fix:

- O parser restaura `count=999` embora o corpo e seu checksum não tenham mudado.

## Expected

Payload e receita visível devem formar uma única unidade íntegra.

## Root cause

O checksum é calculado apenas sobre o código expandido.

## Fix

O codec v2 calcula a integridade sobre payload e corpo. O parser mantém suporte de leitura ao formato legado.

## Verification

- A regressão confirma que adulterar somente o payload degrada para código visível, e que macros legados ainda restauram.

## Impact

- **Users Affected:** edição manual/ corrupção de metadados
- **Frequency:** rara e normalmente intencional
- **Workaround:** não editar as linhas internas do macro

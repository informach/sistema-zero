O exercício se inspira em mecânicas conhecidas: a cobrinha que cresce numa grade
(como o `snake` da coleção Free Python Games, de Grant Jenks, Apache-2.0) e a
lagarta que acelera a cada folha (projeto "Caterpillar" do livro *Computer Coding
Python Projects for Kids*, DK, 2017). Nenhum código desses materiais foi
incorporado. Este é um projeto educacional independente, sem afiliação a eles.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

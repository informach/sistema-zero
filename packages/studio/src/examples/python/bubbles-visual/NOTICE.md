O exercício se inspira numa mecânica conhecida: o submarino que estoura bolhas
contra o relógio, com pontos pelo tamanho e pela rapidez da bolha (projeto
"Bubble Blaster" do livro *Help Your Kids with Computer Coding*, DK, 2ª edição,
2019). Nenhum código desse material foi incorporado. Este é um projeto
educacional independente, sem afiliação a ele.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

O exercício se inspira numa mecânica conhecida: a cesta que apanha ovos que
caem cada vez mais depressa, com três vidas (projeto "Egg Catcher" do livro
*Computer Coding Python Projects for Kids*, DK, 2017). O ovo dourado é um
acréscimo deste exemplo. Nenhum código desse material foi incorporado. Este é
um projeto educacional independente, sem afiliação a ele.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

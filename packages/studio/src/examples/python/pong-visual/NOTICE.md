O exercício se inspira em uma mecânica conhecida: duas raquetes rebatendo uma
bola (como o `pong` da coleção Free Python Games, de Grant Jenks, Apache-2.0, e
o projeto "Ping Pong" do livro *Coding for Kids in Python*, de Ellen Tale,
2020). Nenhum código desses materiais foi incorporado. Este é um projeto
educacional independente, sem afiliação a eles.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

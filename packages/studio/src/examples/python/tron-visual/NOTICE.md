O exercício se inspira em uma mecânica conhecida: duas motos que deixam rastros
e não podem bater neles (como o `tron` da coleção Free Python Games, de Grant
Jenks, Apache-2.0). Nenhum código desse material foi incorporado. Este é um
projeto educacional independente, sem afiliação a ele.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

# Origem

Porta do projeto Python-Monsters da Clear Code (pasta `code (finish)`), a partir do código
fornecido para este projeto. O README do original diz que o código é CC0 (domínio público:
pode ser usado para qualquer fim, inclusive comercial; a atribuição é bem-vinda, mas não
obrigatória). A estrutura, as classes, os dados e as regras são as do original; a derrota com
volta à enfermeira, a arena dos campeões (os treinadores `t3`, `t4` e `t6`, o guarda do portão
e a entrada no mundo, que o original não chegou a fazer) e as correções descritas no README
foram acrescentadas pelo Sistema Zero.

Os mapas reproduzem o traçado dos mapas originais, convertidos para o Pinta.

A arte (pessoas, monstros, ataques, cenários, peças do chão, prédios e objetos) foi desenhada
no Pinta pelo Sistema Zero, e a música e os efeitos sonoros foram sintetizados pelo Sistema
Zero: nenhum arquivo de imagem, som ou fonte do original foi usado. A fonte é a Press Start 2P
(SIL Open Font License).

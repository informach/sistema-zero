# Origem

Porta da etapa "Pong 3 saving" do curso de cinco jogos em pygame-ce da Clear Code
(Christian Koch), a partir do código fornecido para este projeto. Os arquivos
`sprites.py` e `groups.py` são os do original; `settings.py` e `main.py` ganharam a
meta de pontos, a vitória e a revanche.

O jogo desenha tudo com o próprio pygame-ce: não há imagens nem sons.

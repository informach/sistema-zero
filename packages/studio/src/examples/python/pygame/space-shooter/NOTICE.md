# Origem

Porta da etapa "space 10 finishing up" do curso de cinco jogos em pygame-ce da Clear
Code (Christian Koch), a partir do código fornecido para este projeto. A estrutura,
as classes e as regras são as do original; o fim de rodada, a música e o recorde
foram acrescentados.

A arte (nave, meteoros, laser, estrela e explosão) foi desenhada no Pinta pelo
Sistema Zero, e os sons foram sintetizados pelo Sistema Zero: nenhum arquivo de
imagem ou som do original foi usado. A fonte é a Bungee (SIL Open Font License).

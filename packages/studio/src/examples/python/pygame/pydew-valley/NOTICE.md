# Origem

O código deste jogo foi escrito pelo Sistema Zero. O jogo e as regras (a fazenda, as
ferramentas, o plantio, a rega, o crescimento ao dormir, a chuva, as árvores com
maçãs e a loja do comerciante) são inspirados no tutorial PyDew Valley, de Christian
Koch (Clear Code), um jogo de fazenda inspirado em Stardew Valley. Começamos de um
porte do código do tutorial e depois o reescrevemos com a nossa própria organização,
mantendo o jogo igual na tela e nos controles. Fica aqui o crédito, com gratidão, à
Clear Code pela inspiração.

A arte (fazendeiro, comerciante, árvores, plantas, casa, terreno, chuva, água, terra
e ícones) foi desenhada no Pinta pelo Sistema Zero, e os sons e a música foram
sintetizados pelo Sistema Zero: nenhum arquivo de imagem ou som do tutorial é usado.

O traçado dos mapas segue o do tutorial: a posição de cada peça, das casas, da cerca,
das árvores, das plantas e dos outros objetos foi convertida do mapa original
(`map.tmx`) para os mapas do Pinta. As peças que preenchem esse traçado foram
redesenhadas por nós, e nenhuma imagem do mapa original é usada. A fonte é a Fredoka
(SIL Open Font License).

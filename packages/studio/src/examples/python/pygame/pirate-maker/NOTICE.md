# Origem

Porta da etapa final ("28_finish") do projeto PirateMaker, de Christian Koch (Clear Code),
um jogo inspirado no Mario Maker. Segundo o README do projeto, o código está em domínio
público (CC0 1.0): pode ser copiado, modificado e distribuído, inclusive para fins
comerciais, sem pedir permissão. Os módulos, as classes e as regras são os do original;
mudaram o carregamento das imagens e dos sons (agora pelo módulo `pinta`), a escolha da
peça do terreno (47 peças no lugar de 232 imagens) e a fase sem terreno, que não fecha mais
o jogo. O modo de jogo ganhou o que o original não tinha: corações, contador de moedas,
fim de jogo e fase completa.

A arte (terreno, água, pirata, Dente, concha, pérola, espinhos, moedas, diamante, brilho,
palmeiras, nuvens, cursor, corações, ícones do menu e prévias) foi desenhada no Pinta pelo Sistema
Zero, e os sons e as duas músicas foram sintetizados pelo Sistema Zero: nenhum arquivo de
imagem ou som do original foi usado.

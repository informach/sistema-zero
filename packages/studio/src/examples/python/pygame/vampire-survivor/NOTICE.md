# Origem

Porta da etapa "Vampire 7 finish" do jogo Vampire Survivor, do curso de cinco jogos
em pygame-ce da Clear Code (Christian Koch), a partir do código fornecido para este
projeto. Os módulos, as classes e as regras são os do original, e o mapa reproduz o
level design dele (muros, pedras, árvores, colunas, colisões e os pontos onde o
caçador começa e os monstros nascem). A vida do caçador, a tela de início, o fim de
jogo com tempo e monstros derrotados, o recomeço e a música foram acrescentados.

A arte (caçador, morcego, gosma, esqueleto, arma, bala, ícones, árvores, colunas,
pedras, peças do chão e o mapa) foi desenhada no Pinta pelo Sistema Zero, e os sons e
a música foram sintetizados pelo Sistema Zero: nenhum arquivo de imagem ou som do
original foi usado. A fonte é a Bungee (SIL Open Font License).

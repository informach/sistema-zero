# Origem

Porta da etapa "Platform 4 finish" do curso de cinco jogos em pygame-ce da Clear Code
(Christian Koch), a partir do código fornecido para este projeto. Os módulos, as classes e
as regras são os do original (`main`, `groups`, `settings`, `sprites`, `support` e `timer`);
o nível é o mesmo mapa de 45 × 25 casas, com as plataformas, os enfeites, o ponto de partida
e os caminhos das minhocas nos mesmos lugares. Os corações, as telas de início, vitória e fim
de jogo, a bandeira de chegada, o placar e a música tocando foram acrescentados.

A arte (o explorador, as abelhas, as minhocas, o tiro e o clarão, a bandeira, os corações,
as peças do terreno e dos enfeites e o mapa) foi desenhada no Pinta pelo Sistema Zero, e os
sons foram sintetizados pelo Sistema Zero: nenhum arquivo de imagem ou som do original foi
usado. As fontes são a Bungee e a Nunito (SIL Open Font License).

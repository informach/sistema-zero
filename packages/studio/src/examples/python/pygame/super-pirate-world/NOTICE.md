# Origem

Porta do projeto "Super Pirate World" de Christian Koch (Clear Code), a partir da pasta
`code_complete` dos arquivos do tutorial. O código original foi publicado sob a licença
Creative Commons 0 (CC0), que permite uso pessoal e comercial sem pedir autorização; o crédito
não é obrigatório, mas fica registrado aqui com gratidão. A estrutura, as classes e as regras
são as do original; o carregamento dos desenhos, as fases liberadas em sequência, as telas de
título, fim de jogo e vitória e as tábuas da fase 4 foram acrescentados, e o level design das
seis fases e do mapa do mundo foi convertido dos mapas originais.

A arte (pirata, inimigos, armadilhas, itens, cenários, peças e mapas) foi desenhada no Pinta
pelo Sistema Zero, e os sons e a música foram sintetizados pelo Sistema Zero: nenhum arquivo de
imagem ou som do original foi usado. As fontes são a Bungee e a Press Start 2P (SIL Open Font
License).

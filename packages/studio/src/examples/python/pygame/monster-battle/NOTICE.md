# Origem

Porta da etapa "Monster 5 finish" do jogo Monster Battle, do curso de cinco jogos em
pygame-ce da Clear Code (Christian Koch), a partir do código fornecido para este
projeto. Os módulos, as classes e as regras são os do original (`attack.py` e
`timer.py` estão iguais); o carregamento dos desenhos e dos sons passou a usar o
módulo `pinta`, e a tela de início, a tela de fim com recomeço, a respiração dos
monstros e os ícones do menu foram acrescentados. Os textos da tela foram traduzidos
para o português; as chaves dos dicionários continuam as do original.

A arte (os 16 monstros de frente e de costas e os ícones deles, as animações de
ataque, os ícones das habilidades e do menu, o gramado e a arena) foi desenhada no
Pinta pelo Sistema Zero, e os sons e a música foram sintetizados pelo Sistema Zero:
nenhum arquivo de imagem ou som do original foi usado. A fonte das telas de início e
de fim é a Bungee (SIL Open Font License).

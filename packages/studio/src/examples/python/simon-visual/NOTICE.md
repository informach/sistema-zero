O exercício se inspira numa mecânica conhecida: o jogo de repetir sequências de
cores do `simonsays` da coleção Free Python Games, de Grant Jenks (Apache-2.0),
que espera com `time.sleep` e termina com `exit()`. Aqui toda espera passa pelo
temporizador da tela, a entrada é ignorada durante a demonstração, as setas e o
clique escolhem as cores e há recorde da sessão. Nenhum código daquela coleção
foi incorporado. Este é um projeto educacional independente, sem afiliação a
ela nem ao brinquedo comercial que popularizou o jogo.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

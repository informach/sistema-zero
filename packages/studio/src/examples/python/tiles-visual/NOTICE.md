O exercício se inspira numa mecânica conhecida: o quebra-cabeça de peças
deslizantes do `tiles` da coleção Free Python Games, de Grant Jenks
(Apache-2.0). Esta versão usa as setas e o clique, embaralha só com movimentos
legais, conta movimentos e tempo e reconhece a vitória. Nenhum código daquela
coleção foi incorporado. Este é um projeto educacional independente, sem
afiliação a ela.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

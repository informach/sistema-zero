O exercício se inspira numa mecânica conhecida: o jogo da velha em turtle do
`tictactoe` da coleção Free Python Games, de Grant Jenks (Apache-2.0), que
desenha as jogadas mas não confere vitória nem casa ocupada. Esta versão
acrescenta essas regras, o empate, o placar e o computador adversário. Nenhum
código daquela coleção foi incorporado. Este é um projeto educacional
independente, sem afiliação a ela.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

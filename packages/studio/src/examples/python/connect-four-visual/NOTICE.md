O exercício se inspira numa mecânica conhecida: as peças que caem numa grade de
colunas do `connect` da coleção Free Python Games, de Grant Jenks (Apache-2.0),
que não confere quem venceu. Esta versão acrescenta a queda animada, a vitória
nas quatro direções, o empate, a coluna cheia recusada e o placar. Nenhum código
daquela coleção foi incorporado. Este é um projeto educacional independente, sem
afiliação a ela.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

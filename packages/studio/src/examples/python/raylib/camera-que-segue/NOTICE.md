Copyright (c) 2026 Sistema Zero. O código deste exemplo é original, distribuído sob a
licença MIT em `LICENSE`.

A mecânica do jogo se inspira em "basics 5 (câmera)" do curso de raylib em Python do canal
Clear Code. Nenhum código, texto, imagem ou som do curso foi incorporado. Este é um projeto
educacional independente, sem afiliação ao Clear Code nem aos autores do raylib.

O programa usa a API do raylib-python-cffi 6.0.1.0 (EPL-2.0) e do raylib
(zlib), e roda no computador com `pip install raylib==6.0.1.0`.

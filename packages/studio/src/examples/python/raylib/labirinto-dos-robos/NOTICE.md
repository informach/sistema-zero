# Autoria e recursos

Copyright (c) 2026 Sistema Zero. O código, os desenhos e os sons deste exemplo são originais, distribuídos sob a
licença MIT em `LICENSE`. Os desenhos foram escritos como código (`scripts/python/raylib-art.ts` no repositório do Sistema Zero). Os sons foram sintetizados a partir de partituras.
As texturas e o céu foram feitos no Molda, a oficina 3D do Sistema Zero
(`scripts/raylib/molda-models.ts`), pelos mesmos caminhos que a criança usa.

A mecânica do jogo se inspira em "Doom-style FPS" do curso de raylib em Python do canal
Clear Code. Nenhum código, texto, imagem ou som do curso foi incorporado. Este é um projeto
educacional independente, sem afiliação ao Clear Code nem aos autores do raylib.

O programa usa a API do raylib-python-cffi 6.0.1.0 (EPL-2.0) e do raylib
(zlib), e roda no computador com `pip install raylib==6.0.1.0`.

# Autoria e recursos

Copyright (c) 2026 Sistema Zero. O código, os desenhos, os sons e a música deste exemplo são originais, distribuídos sob a
licença MIT em `LICENSE`. Os desenhos foram escritos como código (`scripts/python/raylib-art.ts` no repositório do Sistema Zero). Os sons e a música foram sintetizados a partir de partituras.

A fonte `fonts/pressstart2p.ttf` é a Press Start 2P, de CodeMan38, distribuída sob a SIL
Open Font License 1.1 em `LICENSE-fonte.txt`.

A mecânica do jogo se inspira em "Pokemon-style Battle" do curso de raylib em Python do canal
Clear Code. Nenhum código, texto, imagem ou som do curso foi incorporado. Este é um projeto
educacional independente, sem afiliação ao Clear Code nem aos autores do raylib.

O programa usa a API do raylib-python-cffi 6.0.1.0 (EPL-2.0) e do raylib
(zlib), e roda no computador com `pip install raylib==6.0.1.0`.

# Proveniência

Escrito originalmente para o Sistema Zero em 19/10/2026. Os quatro módulos foram criados de novo: não são cópia, tradução ou adaptação linha a linha de programas externos. A inspiração limita-se à mecânica genérica de corrida entre tartarugas com movimento aleatório. A estrutura de estados, escolha sem influência na corrida, contagem, pausa, placar, cruzamento dentro do tick e controle de geração dos timers pertencem a esta implementação.

Não foram reutilizados código ou recursos de [Turtle-Racing-V2](https://github.com/techwithtim/Turtle-Racing-V2), cuja árvore consultada não continha licença. A consulta a Pac-Man, Games-Python-Turtle e Space Arena também não autoriza incorporar seus códigos, sons, imagens, personagens ou marcas. Nenhum desses recursos está neste exemplo.

A arte usa linhas, retângulos, cores, texto e a forma `turtle` da API padrão. O nome genérico Arial é solicitado ao host; não há binário de fonte, GIF, imagem, música ou som distribuído. A única dependência é a biblioteca padrão Python com Turtle, fornecida pelo runtime aprovado. Não se presume uma licença de recurso individual a partir da licença de um repositório.

Documentação primária: [Python 3.14 — Turtle graphics](https://docs.python.org/3.14/library/turtle.html), em especial `Screen`, `Turtle`, `onkey`, `onclick`, `ontimer`, `mainloop` e `bye`. O código original segue as condições de distribuição do produto; este documento não concede direitos em nome de terceiros.

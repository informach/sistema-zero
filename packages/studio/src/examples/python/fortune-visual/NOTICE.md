O exercício se inspira no projeto "Fortune-teller" do livro *Coding with Python:
A Playful Way of Programming*, de Mark B. Bennet (2020), em que o computador responde a perguntas com
frases sorteadas. Aqui a ideia virou uma roda com ponteiro, atrito e
histórico. Nenhum código desse material foi incorporado. Este é um projeto
educacional independente, sem afiliação a ele.

`turtle` é a API padrão do Python. `sz_audio` é o módulo portátil de áudio do
Sistema Zero, distribuído separadamente e incluído pelo exportador do projeto;
não é uma extensão da API Turtle.

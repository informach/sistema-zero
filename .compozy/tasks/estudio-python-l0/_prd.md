# L0: qualificação técnica do Estúdio Python

Este subprojeto produz provas experimentais, sem habilitar Python no produto. Requisitos: [proposta aprovada](../../../docs/plans/2026-10-16-estudio-javascript-python-turtle-proposta.md), [matriz de aceite](../../../docs/plans/2026-10-16-estudio-python-validacao-entregas.md).

O pedido do usuário abrange L0–L8, revisões entre lotes, revisão final, correções, commit e merge local em staging. L0 é a dependência obrigatória da integração, não a entrega completa do recurso. Evidência ausente ou falha deve ser reportada; não se pode aprovar o recurso com testes simulados.

Esta primeira revisão cobre a preparação do runtime, servidor de prova e sondas de navegador; não atribui conclusão aos demais requisitos L0.

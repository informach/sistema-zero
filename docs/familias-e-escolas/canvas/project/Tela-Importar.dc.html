A conta de cada família é criada ou encontrada pelo e-mail do responsável. Cada aluno ganha um bilhete para o primeiro acesso da família e um crachá para os computadores da escola. Sem e-mail, o aluno fica numa conta provisória até o responsável usar o bilhete.

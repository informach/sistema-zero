# BUG-001: Textura e camadas desaparecia no acesso avançado

**Severity:** High
**Priority:** P1
**Type:** Functional
**Status:** Fixed

## Environment

- Build: `staging` local, antes deste review.
- OS/browser: Windows, Chromium no playground do Molda.

## Summary

Ao selecionar uma peça na aba Pintar, o acesso avançado ocultava a entrada **Textura e camadas**. O nível intermediário a mostrava.

## Reproduction

Abrir o playground com acesso `god`, selecionar uma peça e entrar em Pintar. A seção não aparecia.

## Expected

A entrada fechada fica disponível para quem tem `paint.layers`, independentemente de também ter `paint.material`.

## Root cause

`ScenePaintEditor` exigia `!access.can('paint.material')` para montar `SceneAppearanceTools`, excluindo o perfil mais completo.

## Fix

Montar a ferramenta para a peça de malha e deixar `RequiresTool family="paint.layers"` controlar o acesso. Atualizar os limites de inventário para a entrada acrescentada.

## Verification

- Regressão em `SceneWorkshop.toolAccess.test.tsx`: falhou antes da correção e passou depois.
- E2E em `e2e/paint-simple.spec.ts`: abre a seção com acesso completo.
- `bun run test` e `bun run check` no Molda.

## Impact

- **Users affected:** usuários com ferramentas avançadas de pintura.
- **Frequency:** sempre.
- **Workaround:** nenhum no perfil avançado.

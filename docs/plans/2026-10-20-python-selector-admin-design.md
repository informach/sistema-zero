# Liberação JavaScript e seletor Python administrativo

## Decisão confirmada

Em 20/10/2026, o usuário priorizou o lote pedagógico, a integração do código Python, a preservação do JavaScript e o seletor de linguagem somente para administradores. Os administradores criarão projetos Python para validação apenas em staging. Alunos não receberão arquivos Python. Exemplos já possuem visibilidade administrativa.

## Comportamento

As páginas do Estúdio Completo Kids e Adulto oferecem criação Python somente para contas com papel `admin` ou `superadmin`. O host transmite uma opção explícita de apresentação, desativada por padrão. Alunos continuam criando JavaScript, inclusive Pro conforme seus acessos atuais. O catálogo Python, sua consulta e seus avisos não são apresentados a esses alunos.

O código Python permanece integrado. Contas administrativas continuam sujeitas à descoberta real de ambientes disponíveis: esta opção não fabrica autorização, runtime ou infraestrutura funcional. A futura liberação geral altera a decisão de apresentação nos hosts.

Esta é uma regra de oferta na interface, conforme o escopo solicitado. Não altera importação, remix, Mural, publicação, aulas, sala ao vivo ou autorizações de runtime. Não deve ser descrita como bloqueio de segurança contra arquivos Python obtidos por outros meios.

## Pedagogia e gravações

Preservar falas gravadas, montagem, sequência e valores ensinados. Manter os ajustes necessários à verificação dos objetivos. Os candidatos Cadê ainda não ativados e a revisão futura de outras igualdades literais não devem ser publicados como parte deste lote nem tratados como pré-requisito de gravação JavaScript.

## Aceite

- Aluno Kids/Adulto não recebe oferta nem avisos de criação Python; JavaScript permanece padrão.
- Admin/superadmin mantém a oferta Python e a descoberta autenticada existente.
- Staff sem papel administrativo não ganha a oferta apenas por poder ver exemplos.
- Criação JavaScript clássica/Pro, edição, persistência e Pensa continuam funcionando.
- Testes dos cursos, CI e cenários JavaScript pertinentes passam antes de declarar a liberação validada.
- A validação incompleta de Python permanece explícita; não equivale a homologação de desempenho ou publicação pública.

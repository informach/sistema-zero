publicado**: o Admin (upload e "Revisar e publicar") ficou para outra sessão.

## Como terminar a publicação

1. No Admin de cada ambiente, exporte o Como fazer e guarde a cópia (backup).
2. Suba cada webp de `prints/2026-10-20/` pelo upload de imagem do Admin (o `ImageUploader` do passo, ou
   `POST /api/media/images` com `scope=block`) e ponha a URL no `imageUrl` do passo de mesmo id. O `imageAlt` já
   está escrito no lote. Use as mesmas URLs nos dois ambientes (o CDN de produção serve aos dois).
   Atenção: 7 prints recapturados substituem uma URL antiga que ainda está no lote:
   `estudio-criar-um-projeto/novo`.
   `molda-salvar-e-reabrir/reabrir`.
   `molda-usar-no-estudio/adicionar`.
   `pinta-usar-no-estudio/bloco`.
   `pinta-usar-no-estudio/projeto`.
   `plataforma-responder-o-quiz/enviar`.
   `plataforma-responder-o-quiz/responder`.
3. Importe o lote (aba **Importar**) e publique cada tutorial em **Revisar e publicar**. O import só mexe no
   rascunho e substitui o rascunho inteiro: confira antes se algum tutorial tem mídia só no ambiente.
4. Traga o resultado de volta para `como-fazer.json` pelo **Exportar JSON** e apague `prints/2026-10-20/`.

## Como os prints foram capturados

Chrome instalado em headless com o protocolo de depuração (CDP), sem Playwright, como o
`packages/funnel/scripts/captura-telas-kids.ts`: os cookies de uma sessão do Kids entram UMA vez num perfil
temporário do Chrome (o token gira), uma aba recarrega a cada 6 minutos para a sessão não vencer, e quando a
sessão do perfil acaba (cerca de 70 minutos) basta clicar no cartão do perfil em "Quem vai criar hoje?" (o
navegador continua autorizado). O Lipe é da equipe: vê a prévia da equipe ("Prévia das aventuras", moedas ∞,

# Capas das aulas · A Ilha do Farol

As 18 capas finais estão nesta pasta. O nome identifica a aula e a parte exibida na plataforma: `aula-01-parte-01.png`, por exemplo, corresponde à Aula 1, Parte 1.

Ao substituir o vídeo provisório pela gravação final, aplique novamente a imagem correspondente como capa no Vimeo e confira a imagem no player da aula. Cada parte tem um vídeo próprio para conservar sua capa individual.

A Aula 3, Parte 7 é uma revisão sem vídeo. Sua capa foi preparada junto com as demais, mas essa parte não deve receber um vídeo que não existe no manifesto.

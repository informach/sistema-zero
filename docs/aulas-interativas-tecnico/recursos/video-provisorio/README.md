# Vídeo provisório para cadastrar cursos

`video-provisorio-2s.mp4` tem dois segundos de tela preta e áudio silencioso. É um arquivo pequeno para preparar e gravar aulas em staging antes de substituir pelos vídeos finais.

O arquivo pode ser reutilizado em todos os cursos. Cadastre uma mídia independente para cada parte que tenha uma capa própria: a miniatura do Vimeo pertence ao vídeo, portanto reutilizar o mesmo ID em várias partes também reutilizaria a mesma miniatura.

O vídeo provisório substitui somente a mídia. Conserve os manifestos, as atividades, os projetos, os materiais e as capas reais de cada curso. Ao enviar a gravação final, preserve a capa correspondente.

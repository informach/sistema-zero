**Goal:** Reutilizar os arquivos públicos imutáveis do interpretador, mantendo um worker e um ambiente Python novos a cada execução.

**Architecture:** O contexto confiável carrega arquivos de uma distribuição aprovada e os guarda explicitamente em CacheStorage; o ambiente opaco recebe somente bytes de nomes fechados, verificados por tamanho e SHA inclusive na leitura do cache. Os módulos pinados do Pyodide recebem uma dependência lexical de leitura via `esbuild.inject`, sem alterar `globalThis.fetch`, a API pública `loadPyodide`, o sandbox ou os arquivos originais de entrada. Esta arquitetura ainda é candidata: primeiro precisa passar pela prova isolada abaixo.

**Tech Stack:** Pyodide 314.0.7 / CPython 3.14.2, esbuild 0.28.1, MessagePort, Chrome/Edge, Node 24 e servidor Bun local.

**Spec:** `docs/plans/2026-10-16-estudio-python-desempenho.md`, `docs/superpowers/plans/2026-10-16-studio-python-stdlib-performance.md`, review de design `.cache/studio-python-l0/review-scoped-pyodide-fetch-design.md`.

## Restrições globais

- Preservar JavaScript e isolamento opaco: nenhum `allow-same-origin` no frame que executa código do aluno.
- Não reusar interpretador, filesystem ou globais do aluno entre execuções.
- Somente GET de arquivos públicos pinados, sem URLs do projeto, credenciais, redirects, query, body ou headers arbitrários.
- O manifesto confiável determina nome/tamanho/SHA; uma mensagem do filho nunca concede autoridade fornecendo seu próprio hash.
- A adaptação fornece somente o subconjunto de Response usado pelo loader. Não promete equivalência de `url`, `type` e `redirected`; não copiar Content-Encoding de um corpo já decodificado.
- Verificação antes da transferência perde sobreposição de compilação WASM com download frio. Medir tempo/memória, sem declarar ganho antes dos resultados.
- Não usar `createPyodideModule`: o contrato pinado o considera experimental e destinado a Service Workers. Manter import dinâmico original do módulo asm derivado.
- Nenhuma alteração de produção nesta primeira prova. Não confundir sucesso do protótipo com aprovação do produto.
